下载完整安装包后，请解压整个文件夹并运行 `MassScope.exe`，同时保留同目录下的 `_internal` 文件夹。

## 已有版本升级

在软件中打开“⋯ → 关于 → 检查更新”，由软件自动选择匹配的增量补丁。1.22.0、1.22.1、1.22.2、1.22.3 和 1.23.0 可直接升级到 1.23.1；其他版本可下载完整包解压到新目录运行。

资源列表中的 `.sha256`、`MassScope-update.json` 和 `.sig` 用于更新校验，普通用户无需单独下载。手动下载补丁时，起始版本必须匹配；推荐通过软件内更新安装。

## 本版更新

- 图内文字、图例名称及横纵轴标题统一支持上标、下标，项目和图片导出保留格式。
- 分栏子图等高、对齐，共用居中的轴标题，各图保留自己的图例；修复导出布局和坐标范围。
- 点击绘图区空白处清除选点，方便截图。
- 数据图层颜色圆点固定显示，行高更紧凑，日期按空间精简，“时间”开关记住偏好。
- 修复文字格式重置、长文字截断、旧标注恢复及窗口清理期间的异常。
